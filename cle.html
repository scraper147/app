Préparer la clé d’accès

Pour un commerce qui enregistre ses données dans son propre dépôt GitHub privé. Tout se passe dans ce navigateur : le jeton n’est envoyé qu’à GitHub, pour vérifier l’accès, puis il est chiffré avec la phrase de passe.

1. Le dépôt et le jeton

  1. Créer un dépôt privé vide sur GitHub (ex. mon-commerce-donnees).
  2. Créer un jeton : GitHub › Settings › Developer settings › Fine-grained tokens, accès à ce seul dépôt, permission Contents : Read and write, date d’expiration (un an au plus).

2. La phrase de passe

Elle sera demandée une fois sur chaque appareil (tablettes, Admin). Quatre ou cinq mots sans lien entre eux, au moins 20 caractères. Elle n’est enregistrée nulle part : si elle est perdue, il faut préparer une nouvelle clé.

3. La clé à transmettre

Envoyez ce texte à la personne qui gère les accès (écran superAdmin). Il ne contient ni le jeton ni le dépôt en clair.
